# BSTS Stock Screener

An institutional-grade technical scanner for NSE Midcap and Smallcap stocks engineered to identify high-momentum structural breakouts.

## Features
- **Clean Architecture:** Fully modularized design with separation of concerns.
- **Multithreading:** Rapidly scans hundreds of assets concurrently.
- **Dynamic Watchlist:** Automatically pulls live NIFTY Midcap 150 and Smallcap 250 constituents.
- **Advanced Filtering:** Range expansion, trend alignment, and multi-timeframe price action gates.

## Installation & Requirements
1. Clone the repository.
2. Run `pip install -r requirements.txt`.
3. Execute `python main.py` to start the scan.
